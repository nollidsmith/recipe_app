# PantryPilot Onboarding

**Status:** Forward-looking Section 0 draft

## Prerequisites

- Git
- Node.js and npm: exact supported versions UNKNOWN until the scaffold is created
- A Supabase project for development
- A GitHub account with repository access

## Local setup

1. Clone the repository.
2. Install dependencies with the package manager documented by the scaffold.
3. Copy `.env.example` to `.env.local`.
4. Add development Supabase values.
5. Run migrations or database setup commands.
6. Start the Vite development server.
7. Run the check and test commands before opening a pull request.

## Workflow

Use a feature branch, update the relevant task and contract docs, run local checks, open a pull request, and wait for GitHub Actions before merging.
