# T-002 — Implement PantryPilot authentication flow

## Description

Create the first usable PantryPilot entry point with email authentication, configured social-login actions, password recovery, session-aware routing, and a protected hub placeholder.

## Acceptance criteria

- [x] Email/password sign-in is wired to Supabase Auth.
- [x] Account creation is wired to Supabase Auth with email confirmation support.
- [x] Google and Apple OAuth actions use the configured redirect origin.
- [x] Password-reset requests use the configured reset redirect.
- [x] Session state is loaded on startup and kept current with Supabase auth events.
- [x] Unauthenticated users are redirected to `/login`.
- [x] Authenticated users can reach the protected hub and sign out.
- [x] Loading, success, and error states are visible to users.
- [x] Typecheck and production build pass.
- [ ] Configure and verify Google/Apple providers in the Supabase dashboard.
- [x] Add automated auth-flow tests.
