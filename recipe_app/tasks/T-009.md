# T-009 — Import a PDF or paper recipe into an editable draft

## Description

Let an authenticated user upload a PDF or camera/photo of a printed recipe and receive a prefilled recipe form. The import is always a draft; no recipe row is created until the user reviews the fields and explicitly selects Save recipe.

## Acceptance criteria

- [x] The recipe hub and create screen offer PDF/image import.
- [x] Supported files are validated at 10 MB or less and limited to PDF, JPEG, PNG, and WebP.
- [x] Source files are stored privately under an owner-scoped path and are removed after processing.
- [x] A server-side Edge Function validates ownership, invokes the configured extraction provider, and stores only a normalized draft plus warnings/confidence metadata.
- [x] The existing recipe form is populated with the returned draft and displays a review warning.
- [x] Import failures are actionable and never create a recipe automatically.
- [x] Existing manual recipe creation remains unchanged.
- [x] Tests cover file validation, polling states, and the review-before-save boundary.
- [x] Provider output, source paths, ownership, and terminal cleanup behavior are validated by server-side checks.
- [x] Deployment preflight confirms the Edge Functions, private bucket, provider schema, queue/cleanup status, and required Edge Function secrets when configured; live cross-user RLS/Storage verification remains dependent on a separate test project.

## Out of scope

- Reliable cursive handwriting recognition.
- Automatic nutrition, substitutions, pantry matching, or duplicate merging.
- Permanent source-file retention.
- Production provider selection, credentials, and quota values until configured by the repository owner.

## Risks / dependencies

- `GEMINI_API_KEY` must be configured as a Supabase Edge Function secret before imports can run.
- Provider response must match `pantrypilot_recipe_draft_v1`; malformed responses fail closed.
- Database migration and Storage policies must be applied to the target Supabase project before the UI is deployed.
